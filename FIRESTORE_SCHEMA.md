# Firestore Schema Documentation

## Collections Overview

### `users` Collection
Stores user profiles for both students and teachers.

**Document ID**: Firebase Auth UID

**Fields**:
```typescript
{
  uid: string                    // Firebase Auth UID
  email: string                  // User email
  displayName: string            // Full name
  photoUrl?: string              // Optional profile picture URL
  role: "student" | "teacher"    // User role
  groupId: string                // Class/village/group ID
  createdAt: string              // ISO 8601 timestamp
  
  // Student-specific fields (only for role=student)
  xp?: number                    // Total XP earned
  streak?: number                // Current streak in days
  level?: number                 // Computed level
  badges?: string[]              // Array of badge IDs
  language?: "en" | "hi"         // Preferred language
}
```

**Indexes**:
- `groupId` (ascending) + `role` (ascending)

**Example**:
```json
{
  "uid": "abc123",
  "email": "teacher@example.com",
  "displayName": "Ms. Sharma",
  "role": "teacher",
  "groupId": "village_01",
  "createdAt": "2026-08-30T10:00:00Z"
}
```

### `lessons` Collection
Stores teacher-authored lesson content.

**Document ID**: Auto-generated by Firestore

**Fields**:
```typescript
{
  id?: string                    // Firestore document ID
  topicId: string                // Unique topic ID (e.g., "math_addition_123")
  topicName: {                   // Multilingual topic name
    en: string
    hi: string
  }
  subjectId: string              // Subject category (e.g., "math", "science")
  difficulty: number             // Difficulty tier: 1 (easy), 2 (medium), 3 (hard)
  lessonText: {                  // Lesson content
    en: string
    hi: string
  }
  audioUrl?: string              // Firebase Storage URL for audio
  imageUrl?: string              // Firebase Storage URL for image
  questions: QuizQuestion[]      // Array of quiz questions
  groupId: string                // Class/group this lesson belongs to
  authorUid: string              // Teacher who created this
  authorName: string             // Teacher name for display
  status: "draft" | "published"  // Publication status
  createdAt: string              // ISO 8601 timestamp
  updatedAt?: string             // ISO 8601 timestamp
  completionCount: number        // How many students completed
  averageScore: number           // Average quiz score (0-100)
}
```

**QuizQuestion Structure**:
```typescript
{
  id: string                     // Question ID
  text: {                        // Question text
    en: string
    hi: string
  }
  options: string[4]             // 4 answer choices
  correctIndex: number           // Index of correct answer (0-3)
  explanation: {                 // Answer explanation
    en: string
    hi: string
  }
}
```

**Indexes**:
- `groupId` (ascending) + `status` (ascending) + `createdAt` (descending)
- `authorUid` (ascending) + `createdAt` (descending)

**Example**:

### `student_progress` Collection
Stores detailed progress tracking for students.

**Document ID**: Student UID (same as users collection)

**Fields**:
```typescript
{
  studentUid: string             // Student's UID
  groupId: string                // Student's group
  completedLessons: string[]     // Array of completed topic IDs
  topicAccuracy: {               // Map of topicId -> accuracy %
    [topicId: string]: number
  }
  weakestTopic?: {               // Lowest scoring topic
    topicId: string
    topicName: string
    accuracy: number
    attemptsCount: number
  }
  lastActive: string             // ISO 8601 timestamp
}
```

**Indexes**:
- `groupId` (ascending) + `lastActive` (descending)

**Example**:
```json
{
  "studentUid": "student_xyz789",
  "groupId": "village_01",
  "completedLessons": [
    "math_addition",
    "math_subtraction",
    "science_plants"
  ],
  "topicAccuracy": {
    "math_addition": 95.0,
    "math_subtraction": 45.0,
    "science_plants": 80.0
  },
  "weakestTopic": {
    "topicId": "math_subtraction",
    "topicName": "Subtraction",
    "accuracy": 45.0,
    "attemptsCount": 3
  },
  "lastActive": "2026-08-30T09:15:00Z"
}
```

## Security Rules

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper function to check if user is authenticated
    function isSignedIn() {
      return request.auth != null;
    }
    
    // Helper function to check if user is a teacher
    function isTeacher() {
      return isSignedIn() && 
             get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'teacher';
    }
    
    // Helper function to check if user is a student
    function isStudent() {
      return isSignedIn() && 
             get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'student';
    }
    
    // Helper function to check if user belongs to a group
    function belongsToGroup(groupId) {
      return isSignedIn() && 
             get(/databases/$(database)/documents/users/$(request.auth.uid)).data.groupId == groupId;
    }
    
    // Users collection
    match /users/{userId} {
      // Users can read their own profile
      allow read: if isSignedIn() && request.auth.uid == userId;
      
      // Users can create their own profile
      allow create: if isSignedIn() && request.auth.uid == userId;
      
      // Users can update their own profile
      allow update: if isSignedIn() && request.auth.uid == userId;
      
      // Teachers can read students in their group
      allow read: if isTeacher() && 
                     resource.data.groupId == get(/databases/$(database)/documents/users/$(request.auth.uid)).data.groupId &&
                     resource.data.role == 'student';
    }
    
    // Lessons collection
    match /lessons/{lessonId} {
      // Teachers can read all lessons they authored
      allow read: if isTeacher() && resource.data.authorUid == request.auth.uid;
      
      // Teachers can create lessons for their group
      allow create: if isTeacher() && 
                       request.resource.data.groupId == get(/databases/$(database)/documents/users/$(request.auth.uid)).data.groupId;
      
      // Teachers can update/delete their own lessons
      allow update, delete: if isTeacher() && resource.data.authorUid == request.auth.uid;
      
      // Students can read published lessons from their group
      allow read: if isStudent() && 
                     resource.data.status == 'published' &&
                     belongsToGroup(resource.data.groupId);
    }
    
    // Student progress collection
    match /student_progress/{studentId} {
      // Students can read/write their own progress
      allow read, write: if isSignedIn() && request.auth.uid == studentId;
      
      // Teachers can read progress of students in their group
      allow read: if isTeacher() && 
                     belongsToGroup(get(/databases/$(database)/documents/users/$(studentId)).data.groupId);
    }
  }
}
```

## Required Firestore Indexes

1. **users collection**:
   - Composite: `groupId` (Ascending) + `role` (Ascending)

2. **lessons collection**:
   - Composite: `groupId` (Ascending) + `status` (Ascending) + `createdAt` (Descending)
   - Composite: `authorUid` (Ascending) + `createdAt` (Descending)

3. **student_progress collection**:
   - Composite: `groupId` (Ascending) + `lastActive` (Descending)

## Data Flow

### Teacher Creates Lesson
1. Teacher fills out lesson form in app
2. App calls `TeacherContentRepository.saveLesson()`
3. Lesson saved to `lessons` collection with `status: "draft"`
4. Teacher can preview, edit, then publish
5. On publish, `status` updated to `"published"`

### Student Sees New Lesson
1. Student app syncs on startup/network reconnect
2. App queries `lessons` where `groupId == student.groupId` AND `status == "published"`
3. New lessons merged into local Hive cache
4. Home screen reactively updates via Riverpod providers

### Teacher Views Student Progress
1. Teacher dashboard queries `users` where `groupId == teacher.groupId` AND `role == "student"`
2. For each student, fetch `student_progress/{studentUid}`
3. Compute analytics (class pulse, struggling topics)
4. Display on dashboard with real-time updates via Firestore streams
